## 怎么读

1. 每页用 read 工具打开对应 PNG，**看整页**。不要一次读十几页，一页一页看。
2. **九上（b9a）有文字层**：`pdftotext -f <pdfPage> -l <pdfPage> -layout local-textbook/sukey/raw/sukey-九上.pdf -` 可用来校对中文用字。
3. **九下（b9b）没有文字层**：用 `local-textbook/sukey/ocr/九下/` 里的逐页 OCR 校对用字，**一律以页图为准**。OCR 会认错 `I/l/1`、`Ω`、`℃`。
4. 但两者都**不能代替看图**：浮动图打断正文、栏目框、表格结构只有图里有。
5. 阅读顺序：自上而下、自左而右。双栏先左栏到底，再右栏；浮动外框按页面纵向位置插进阅读顺序。
6. 页眉页脚、页码、栏目图标、装饰底纹、页边色带**不登记**。

## 什么算一条（`kind` 取值只有这些）

**平铺，不嵌套。活动/实验这类容器只登记标题行，内部内容各自成条。**

| kind | 什么算一条 | 粒度 |
|---|---|---|
| `heading` | 章名、节名（一、二、三）、节内小标题 | 标题行一条 |
| `para` | 正文自然段 | 一段一条，不按句切 |
| `figure` | 一张图 + 它的图注 | 一个图注覆盖 (a)(b)(c) 多张子图 = 1 条，bbox 取外接框 |
| `table` | 一张表格 | 一张一条 |
| `activity-title` | 「活动 X.Y」「学生实验」的**标题行** | 只登记标题行 |
| `module` | 栏目框：读一读 / 信息快递 / 方法技巧 / 生活 物理 社会 / 国家工程 / 跨学科实践 | 整框一条，即使嵌在活动流程中间也独立成条 |
| `exercise` | 「实践与练习」里的一道题 | 一题一条 |
| `summary` | 「素养进阶 · 内容梳理」的思维导图 | 一张导图一条 |
| `question` | 「素养进阶 · 反思提升」「问题解决」里的一道题 | 一题一条 |

不登记：章首页的栏目导航列表、整页背景照片、栏目小图标、页眉页脚、页码、装饰底纹。

### `figure` 的 region 铁律（历年最容易错的地方）

- **只框图形本身，不含印刷的图注文字行「图 X-Y …」**
- **但必须含 `(a)` `(b)` `(c)` 这类子图标号那一行**
- **图注印在画面上、裁不掉的**（满版出血照片、图注压在图上）→ 该条目加 `"captionOnImage": true`，region 框完整画面
- **一个图注管多大范围就是一条 figure**：局部放大圆、装饰性对照图、同图号的子图，并进这一条，region 取外接框
- **只在另有独立图注时才另立一条**
- 只有外接框会盖到**第三方内容**（别的图、栏目框、警示框）时才拆成两条，两条互写 `overlaps`

**九年级新增难点**：电路图。元件符号密集、引线细、旁边常贴着「图 13-5」和图例。
region 按**整张电路图**框（含电源、开关、元件符号与引线），不要框到单个元件上；
图里的「L₁」「S」这类元件标注属于图形内部，不能排除。

## 输出

写到 `local-textbook/sukey/expected/<清单文件名>`：

```jsonc
{
  "volume": "b9a",
  "chapter": "phy-b9a-c11",
  "pdfPageRange": [8, 22],
  "printedPageRange": ["1", "15"],
  "pageOffset": { "formula": "pdfPage = printedPage + 7" },
  "items": [
    {
      "srcId": "phy-b9a-p001-01",
      "kind": "heading",
      "pdfPage": 8,
      "region": { "x": 0.06, "y": 0.05, "width": 0.60, "height": 0.06 },
      "originalNumber": "第十一章",
      "text": "第十一章 简单机械和功",
      "continuesOn": null
    }
  ]
}
```

字段要求：

- `srcId`：`phy-<册>-p<印刷页码三位>-<两位页内序>`，页内序按阅读顺序从 01 开始，**分配后不改**
- `region`：见规约 §0.2.2。原点左上、`[0,1]`、`x+width ≤ 1`、`y+height ≤ 1`
  - 拿不准就省略 `region`，改填 `regionOmittedReason`（必填其一，不许两个都空）
  - 不许用 `{0,0,1,1}` 或整页框糊弄
- `text`：**原文照抄**该条目开头文字（≤30 字），用于人工核对；不许改写、概括
- `originalNumber`：原书自带编号（`活动 11.2`、`图 11-3`、题号），没有就 `null`
- `continuesOn`：跨页内容填下一页 pdfPage，否则 `null`
- `captionOnImage`：只对 `figure`，见上
- `overlaps`：与同页别的条目相交时，写对方 `srcId` 数组
