## 怎么读

1. 每页用 read 工具打开对应 PNG，**看整页**。
2. `pdftotext -layout` 只能用来校对中文用字，**不能代替看图**（正文被浮动图打断、栏目框、表格结构只有图里有）。
3. 阅读顺序：自上而下、自左而右。**双栏时先左栏到底，再右栏**。
4. 页眉页脚、页码、栏目图标、装饰底纹**不登记**。

## 什么算一条（`kind` 取值只有这些）

**平铺，不嵌套。活动/实验这类容器只登记标题行，内部内容各自成条。任何两条的 region 不得重叠。**

| kind | 什么算一条 | 粒度 |
|---|---|---|
| `heading` | 章名、节名（一、二、三）、节内小标题 | 标题行一条 |
| `para` | 正文自然段 | **一段一条**，不按句切 |
| `figure` | 一张图 + 它的图注 | **一个图注覆盖 (a)(b)(c) 多张子图 = 1 条**，bbox 取外接框。**region 不含印刷图注那一行，但必须含 (a)(b)(c) 标号行** |
| `table` | 一张表格 | 一张一条 |
| `activity-title` | 「活动 X.Y」「学生实验」的**标题行** | 只登记标题行；后面的步骤、图、表、栏目各自成条 |
| `module` | 栏目框：读一读 / 信息快递 / 方法技巧 / 生活 物理 社会 / 国家工程 / 跨学科实践 | **整框一条**，即使嵌在活动流程中间也独立成条 |
| `exercise` | 「实践与练习」里的一道题 | 一题一条（按 1. 2. 3. 编号切） |
| `summary` | 「素养进阶 · 内容梳理」的思维导图 | 一张导图一条 |
| `question` | 「素养进阶 · 反思提升」「问题解决」里的一道题 | 一题一条 |

不登记：章首页的栏目导航列表（按目录处理）、整页背景照片、栏目小图标、页眉页脚、页码、装饰底纹。

## 输出

写到 `local-textbook/sukey/expected/b8a-c01-p018-025.json`：

```jsonc
{
  "volume": "b8a",
  "chapter": "phy-b8a-c01",
  "pdfPageRange": [18, 25],
  "printedPageRange": ["11", "18"],
  "pageOffset": { "formula": "pdfPage = printedPage + 7" },
  "items": [
    {
      "srcId": "phy-b8a-p011-01",
      "kind": "heading",
      "pdfPage": 18,
      "region": { "x": 0.06, "y": 0.05, "width": 0.60, "height": 0.06 },
      "originalNumber": "第一章 声现象",
      "text": "第一章 声现象",
      "continuesOn": null
    }
  ]
}
```

字段要求：

- `srcId`：`phy-b8a-p<印刷页码三位>-<两位页内序>`，页内序按阅读顺序从 01 开始
- `region`：见规约 §0.2.2。原点左上、`[0,1]`、`x+width ≤ 1`、`y+height ≤ 1`
  - **拿不准就省略 `region`，改填 `regionOmittedReason`**（必填其一，不许两个都空）
  - 不许用 `{0,0,1,1}` 或整页框糊弄
- `text`：**原文照抄**该条目的开头文字（不超过 30 字），用于人工核对；不许改写、概括
- `originalNumber`：原书自带编号（`活动 1.2`、`图 1-3`、题号），没有就 `null`
- `continuesOn`：跨页内容填下一页的 pdfPage，否则 `null`
