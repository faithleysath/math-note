# 任务书：九年级审计 / 修复 / 复审 / 视觉复核

> 执行者：子代理。**禁止创建子代理。**
> 上位规范：`docs/plans/transcribe-spec.md`。先读 §4（type 映射）、§7（关系）、§7.0（谓词决策表）、§13（禁止清单）。

**审计只读，修复另派，复审再换一个实例。** 一份审计报告不许顺手改文件——否则事后分不清哪些改动是谁做的、依据是什么。

---

## A. 章审计（一章一份报告）

输入：

- `local-textbook/sukey/parts/<该章的 1–2 份 part>.json`（逐节点逐边读全文）
- `local-textbook/sukey/expected/<同名>.json`（覆盖率的分母）
- 页图 `local-textbook/sukey/pages/<册>/pXXXX.png`（**逐页打开看**，不能只读 JSON）
- 九上无文字层问题，可用 `pdftotext -layout` 校对；九下用 `ocr/九下/<pdf页>.txt`

输出：`local-textbook/sukey/audit/<册>-c<章号>.md`，**不改任何 part 文件**。

### 查什么（按顺序，每项都要给结论）

1. **断言有没有立命题**。原书用「说明 / 可知 / 表明 / 结论是 / 大量实验表明」引出的可判真假句子，如果被写进 `note(explanation)` 的正文里而不是独立 `proposition`，逐条列出。
2. **伪定义**。`definition` 必须是「术语 + 它的界定」。下列是误判：
   - 栏目容器（信息快递整框）当 `definition`
   - 描述性段落被冠上术语就成 `definition`（「把……的现象叫作……」但原书没有给术语名）
   - 同一个术语在多个 part 里各建一个 `definition` 节点（**查 `entities.json`**）
3. **过度拆分**。一个 srcId 拆成 `@1` `@2` 是对的；拆成 3 个以上碎节点要逐条问「它们语义真的不同类吗」。
4. **漏抄 / 错抄**。逐页比对：框内文字、表格行、公式、单位、上下标、图注原文。**公式和单位是九年级重灾区**（`\Omega`、`\text{kW·h}`、`\mathrm{A}`、`10^3`）。
5. **元话语**。正文里出现「图中层级已结构化」「该栏目属于」「此处原书用表格」这类写给读者以外的人看的话，一律列出。
6. **`citation.page` 对不对**。拿节点里的原文去页图找，页号必须对得上。
7. **电路图/仪器图的 asset**。region 是否框住整张图（含元件标注与引线）、caption 是否原文、`captionOnImage` 用得对不对。

### 抽样判据必须可复述

不许说「抽查了若干」。写成：

> 从该章 N 个节点里等距取 `floor(i·N/k)`，k=…；从 M 条边里按谓词分组等距取样，下标列在文末。

## B. 关系审计（一册一份报告）

输入：`merged/all.json` 里两端任一为该册的边 + 页图。

输出：`local-textbook/sukey/audit/<册>-edges.md`。

### 必查四类

1. **谓词误用**。最高频错判是「用到了」写成 `depends-on`。装置的原理、技术应用、生活实例一律 `uses`。
   还有：`covers` 写成主题词匹配（题目只是提到某概念，不考它）。
2. **依据是否支持谓词**。每条抽样边去页图找 `note` 抄的那句原话，判三档：
   - 成立：依据句逐字存在，且语义正好是该谓词
   - 部分成立：依据存在但只支撑一半 / 需要跨页推断
   - 不成立：依据句在书上找不到，或压根不是这个意思
3. **星形中心**。同一目标被 ≥4 个节点依赖 → 它大概率是主题词不是前置，逐条复核。
4. **`is-a` / `part-of` 混淆**。「X 是 Y 的一种」vs「X 是 Y 的组成部分」，两端都必须是 `definition`。

### 报告要求（重要）

**记 `from → predicate → to` 和依据原句，不要只记边 id。** 边 id 每次合并都会重排，审计报告里的 id 在修复后就失效了。
可以附 id，但主键必须是三元组 + 标题。

---

## C. 修复（换一个代理，不许和审计是同一个）

输入：审计报告 + part 文件。

规则：

1. **先改指，改不了再删**。八上直接删了 66 条假边 → 137 个节点变孤儿 → 事后补了 41 条。
   如果依据成立、只是端点选错了，**换端点**。优先「把断言拆成独立命题再指过去」。
2. **不许为消除孤立而硬连**。零条边好过错一条边。纯实践调查题、栏目容器、编者按本来就该孤立。
3. **改完必须报孤立节点变化**：改前多少、改后多少、新增的逐个说明为什么可以孤着。
4. **改完必须重跑**：

```bash
bun run check:part <part> --expected <清单>; echo "exit=$?"
```

5. 修完在报告里写：改了什么（from → predicate → to 的前后对比）、删了什么及理由、孤立变化。

**修复本身有 25% 的错误率**（八下实测：40 多处修复里抽 20 处，5 处没修好，其中一处是「伪定义换了个形态还没解决」）。
所以修完必须进 D。

---

## D. 修复后复审（再换一个实例，不许是 C 的代理）

输入：修复后的 part + C 的报告。

- 对 C 报告的每一处修复**逐条**判：真修好了 / 换了个形态还没解决 / 修错了
- 抽样另一批本来没被点名的边，看有没有被 C 改坏
- 输出：`local-textbook/sukey/audit/post-fix-review-<册>.md`，结论只写三档，每条附页图证据

---

## E. 视觉复核（逐页，不是抽样）

**必须给三个输入**，少一个就会误报：

1. 页图 `pages/<册>/pXXXX.png`
2. 清单 `expected/<清单>.json`
3. 合并后的 `merged/all.json`（拿它判断「这块内容到底有没有被转写」，而不是只看清单）

第四五章曾因为只给前两个，把 `extraRegions` 覆盖的页误判成「整页漏块」。

### 逐页判什么

- 页面上每一块可见内容，在 `all.json` 里是否都有对应节点（按 `citation.page` + 内容比对）
- 有没有整块漏掉（栏目框、图表、章末栏目）
- 图注有没有重复显示（`captionOnImage` 用对了吗）
- 有没有把两块不相干的内容合成一个节点

### 输出

`local-textbook/sukey/review/<册>-c<章号>.json`：

```jsonc
{
  "chapter": "phy-b9a-c13",
  "pages": [{ "printedPage": "62", "pdfPage": 69, "verdict": "ok|defect", "notes": "…" }],
  "defects": [{ "printedPage": "64", "kind": "missing-block|wrong-region|caption-duplicated|merged-wrong", "detail": "…" }]
}
```

**每一页都要有记录**，哪怕是 `ok`。缺页 = 没复核。

复核完更新 `coverage.md` 的第二栏（那栏由 `report:coverage` 生成，复核状态由你在 `review/` 里落盘后重跑生成）。
