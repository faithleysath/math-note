# 转写规约：苏科版初中物理整书 → v9 JSON

> 本文件是整书转写的**唯一标准**，不是提示词。所有转写、枚举、汇总子代理必须逐条遵守。
> 违反本规约的产出在合并阶段会被机械校验打回，不由人工求情。
>
> 相关实现：`src/lib/book-part.ts`（分章中间格式）、`src/lib/coords.ts`（坐标换算）、
> `scripts/check-book-part.ts`（单章校验）、`scripts/merge-book-parts.ts`（合并成 v9）。

---

## 0. 适用与优先级

1. 本规约约束 Pass 1（源条目枚举）、Pass 2（内容转写）、合并与校验。
2. **§0.1、§0.2、§0.3 优先于全文任何其它表述**。冲突时以本节为准。
3. 规约没覆盖的情况：选最保守的合法表达，写进例外清单，不要自行发明。

## 0.1 转写确定性条款

1. **唯一事实来源**：指定版次的 PDF 及其 sha256、版权页、目录。所有批次用同一份文件。禁止用网络资料、其他版次、其他出版社的内容补写。
2. **ID 优先级**：`branch` / `section` 用结构 ID；**其余一切内容节点用页码 ID**。同一源条目拆分用 `@1`、`@2`。已分配的 ID 永不重新分配。
3. **源条目清单冻结**：每批次开跑前 Pass 1 清单必须已冻结。Pass 2 只能映射清单内的 `srcId`，**不得新增、不得删除、不得改号**。发现清单有误，提异常，不改清单。
4. **覆盖率分母是清单**，不是子代理自述。完整映射 / 明确例外 / 遗漏 / 重复 / 无法判定分别计数，未转写不得计为完成。
5. **关系白名单**：只用 §7 的 7 种谓词。`implies`、`iff`、`proves`、`generalizes`、`refutes` 本次一律禁用。不得凭关键词共现或主观经验连边。
6. **跨批次实体**：核心概念节点以 §9 的实体注册表为准。未查证就新建重复核心概念节点 = 违规。
7. **结构合法性**：任何产出必须通过 v9 Schema 与全图约束。**不能因为原书是某种排版，就造出 Schema 不允许的父子结构**。
8. **资源完整性**：每个 `asset://` 引用必须有对应资源记录且文件存在。坐标不确定就不填 `region`，进待处理清单，**不许用零值或整页框假装定位完成**。
9. **不可判断时**：不发明类型、关系、页码、原文、图注、解释。优先保存原文，用保守合法映射，登记例外。
10. **提交前必须通过**：JSON 结构、ID 唯一、父子类型、关系端点、资源引用、`srcId` 覆盖率。不可通过的批次禁止进入合并。

## 0.2 坐标规范（不可变）

> 本节定义 `region` 与 `pdfPage` 的判定标准。任何工具、任何代理都必须按此换算，不得各写一套。

### 0.2.1 `pdfPage`

- **从 1 开始**，指 PDF 文件中的**物理页序**，不是书内印刷页码。
- `pdfPage = 1` 对应 PDF 第一页。
- 渲染页面统一以 **`/CropBox`** 为可见区域；`/CropBox` 缺失时按 PDF 规范回退（先取 `/CropBox`，无则 `/MediaBox`），不得默认 `/MediaBox`。
- **`/Rotate` 必须应用到渲染结果**（0/90/180/270）。渲染出来的图就是人翻书看到的方向。
- `citation.page` 独立保存原书印刷页码，与 `pdfPage` 无推导关系。**禁止在转写时用固定偏移量换算**（即使本套书四册偏移都是 +7，也不得硬编码）；需要映射时查 `manifest.json` 的 `pageOffset`。

### 0.2.2 `region`

```ts
interface Region {
  x: number;
  y: number;
  width: number;
  height: number;
}
```

- 坐标系：**应用 `/CropBox` 与 `/Rotate` 之后的完整可见渲染页面**。
- 原点在**左上角**，x 向右，y 向下，归一化到 `[0, 1]`。
- 合法条件（校验器强制，浮点容差 `EPS = 1e-6`）：

```
0 <= x < 1
0 <= y < 1
0 < width  &&  x + width  <= 1
0 < height &&  y + height <= 1
```

- 四个值都必须是有限数。`NaN`、`Infinity`、`-Infinity` 一律拒绝。
- 边界校验带容差，**禁止静默裁剪非法坐标**。越界就是错误，不是警告。
- 一个 `region` **只能属于一个 `pdfPage`**。跨页内容必须拆成多个 `SourceAnchor`，每个锚点绑定自己的 `pdfPage + region`，不许让一个 bbox 越过页边界。
- 坐标未知时**整个 `region` 省略**，并记进 `report.md` 的待处理清单（写明原因，如「矢量插图，视觉模型无法给出可靠 bbox」）。

### 0.2.3 换算职责

| 场景 | 换算 |
|---|---|
| 视觉模型读整页渲染图给出 bbox | 已在渲染页坐标系，直接用，仅做范围校验 |
| 从 PDF 对象框（`pdfimages`/`pdftotext -bbox`）反查 | 必须经 `/CropBox` + `/Rotate` 换算到渲染页坐标系 |
| 按 `region` 裁图 | 渲染页像素尺寸 × region → 像素矩形，四舍五入到整数 |

换算函数统一放 `src/lib/coords.ts`，**禁止在各批次脚本里重写**。

## 0.3 覆盖率与复核状态（两个独立指标）

**结构覆盖率**（可机械计算）：

```
结构覆盖率 = 已映射 srcId 数 / 清单中 srcId 总数
```
分类计数：`mapped`（完整映射）/ `exception`（有据可查的例外）/ `missing`（遗漏）/ `duplicate`（一个 srcId 映射到多个互不相关的节点）/ `undecided`（无法判定）。
**只有 `mapped + exception` 计入分子**，`missing`/`undecided` 必须显式列出。

**视觉复核状态**（不可由代码宣称）：

- `unreviewed` / `spot-checked`（人工或独立视觉抽查，记录抽查页）/ `fully-reviewed`
- 结构覆盖率 100% **不代表**视觉复核完成。两者在报告里分两栏写，禁止合并成一个「完成度」。

`pdfimages -list` 的内嵌图对象数**只作为辅助指标**，不等价于页面可见插图数（存在重复图像对象、遮罩、矢量插图）。它异常时提示复查，不当作通过/失败的判据。

## 1. 全局结构

一本教材 = 一个 v9 图。四册是 `branch` 节点，不是四本书。

```
初中物理（苏科版）              ← book.title, stage='junior', subject='physics'
├─ branch 八年级上册            ← id: phy-b8a
│   └─ section(chapter) 第一章 声现象
│       ├─ section 一、声音是什么
│           ├─ note(experiment) 活动 1.2 探究声音的传播
│           ├─ proposition(law) 声音的传播需要介质   ← 兄弟，不是 note 的子节点
│           └─ problem(exercise) 实践与练习 第 1 题
├─ branch 八年级下册            ← id: phy-b8b
├─ branch 九年级上册            ← id: phy-b9a
└─ branch 九年级下册            ← id: phy-b9b
```

### 1.1 已核实的事实（直接来自 PDF 原文，可直接引用）
| 项 | 值 |
|---|---|
| 版次 | 2024 年第 4 版，江苏凤凰科学技术出版社 |
| 四册页数 | 八上 158 / 八下 138 / 九上 118 / 九下 122（共 536 页） |
| 章号 | **全书连续 1–18**：八上 1–5、八下 6–10、九上 11–14、九下 15–18 |
| 页码偏移 | 四册均为 `pdfPage = printedPage + 7`；PDF 1–7 为无页码前置页（封面/书名/版权/致同学/目录×2/空白） |
| 文字层 | 八上、九上有；八下、九下为逐页图重建，**无文字层**（已另备 OCR 作辅助） |

章 ID 用全局章号：八下第 7 章 = `phy-b8b-c07`。

**特殊结构（已核实）：**

- 「引言」是一章级单元（八上印刷 1–10，PDF 8–17），章 ID 用 `phy-<册>-c00`，`type=section`、`kind=chapter`。
- **「跨学科实践」在目录里是章内条目**（如「跨学科实践：乐器的调查与制作」），位于章末、还没到「素养进阶」。定作 `section(kind='subsection')` 下的 `note(topic)`，不要让整个章都变成 note。
- **「素养进阶」不在目录里**，但它确实占篇幅（章末 2–3 页），必须建节点，不能因为目录没写就不转。

父容器的合法子类型（`allowedChildTypes`，硬约束）：

| 父 | 允许的子 |
|---|---|
| `branch` | `section`、`note` |
| `section` | `section`、`definition`、`proposition`、`proof`、`problem`、`note`、`counterexample` |
| `note` | **只有 `note`** |

推论：**实验结论、活动里的知识点，一律挂到所属 `section` 下当兄弟节点**，不能挂在 `note(experiment)` 下面。`branch` 下也不能直接挂 `proposition`。

## 2. ID 规则

| 对象 | 格式 | 示例 |
|---|---|---|
| 册分支 | `phy-<册>` | `phy-b8a` |
| 章 | `phy-<册>-c<两位章号>` | `phy-b8a-c04` |
| 节 | `<章id>-s<两位节号>` | `phy-b8a-c04-s02` |
| 子节 | `<节id>-ss<两位序号>` | `phy-b8a-c04-s02-ss01` |
| 内容节点（note/definition/proposition/problem） | `phy-<册>-p<印刷页码三或四位>-<两位页内序>` | `phy-b8a-p045-02` |
| 拆分节点 | 上一条 + `@n` | `phy-b8a-p045-02@1` |
| 边 | `<章id>-e<三位序号>` | `phy-b8a-c04-e007` |
| 推理步骤 | `<章id>-i<三位序号>` | `phy-b8a-c04-i001` |
| 资源 | `phy-<册>-p<页码>-fig<两位>` | `phy-b8a-p045-fig01` |

**优先级（消除双轨）：**

- `branch` / `section` 用结构 ID。
- **一切实际内容节点用页码 ID**，包括活动、实验、例题、讲解、定义、命题。
- 栏目号（「活动 4.2」「例题 3」）**不进节点 ID**，只进 `citation.originalNumber` 和 `srcId`。
- 页内序按页面从上到下、从左到右，Pass 1 分配；**分配后不改**。
- `@1`/`@2` 必须源自同一个 `srcId`，拆分顺序一次定死，后续编辑不得重排。
- ID 撞车：后到的批次必须**报异常**，不得自行改名或加后缀。

## 3. 源条目清单（Pass 1）

### 3.1 定义什么算一个源条目

**只有视觉上真正成框的容器可以包含子条目**，其余一律平铺。

- **可嵌套的容器**：`module` —— 信息快递 / 读一读 / 方法技巧 / 生活 物理 社会 / 国家工程 / 跨学科实践，
  以及版面里独立的**警示框、提示框**（不属于 10 个栏目也按 `module` 算）。
  框内有图时：`module` 的 `region` 覆盖**整个框**，图单独成条并标 `parentSrcId` 指向该 module。
  「成框」**不限于虚线/实线边框**：带栏目标识（徽标、色带、红标、独立标题样式）的整块也算成框。
  例如「读一读」常常没有边框，只有书本图标 + 下划线标题，仍然是一个 `module`。
- **活动 / 学生实验不是框**，视觉上没有边框，所以不做嵌套：标题行单独一条（`activity-title`），
  其后的步骤段落、图、表、栏目**各自独立成条**，按阅读顺序紧跟其后。
- **重叠规则（最终版）**：
  - 父子的 bbox **完全包含**是合法的（子必须整个落进父里）
  - **部分相交允许**，但必须双方都在 `overlaps` 数组里写明对方的 `srcId`
  - **相交却没声明 = 校验 error**
  - **跨 part 的边是允许的**：`edge.from`/`edge.to` 可以指向别的 part 里的节点，只要 ID 符合 §2 的命名规约。
  单章校验会把这种端点降级为 warning（`external-endpoint`），**合并时统一做硬校验**。
  跨章的前置依赖（`depends-on`）只能这么表达，不要因为「端点不在本 part」就放弃连边。
- **跨页父框的子条目不要填 `parentSrcId`**：包含关系只在**单页内**成立。
    父条目若靠 `extraRegions` 跨页（例如跨页的跨学科实践大框），续页上的子条目一律
    `parentSrcId: null`。它们的归属由 Pass 2 按上下文决定，不要指望 bbox 包含。

  为什么允许相交：**bbox 失真比重叠更糟**。重叠是可见的、能人工复查的；
  为了绕开重叠而把图框切小，会让裁出来的图缺一块，这种损失事后看不出来。
  典型例子：图里带放大圆插图、旁边紧贴警示框，宁可让外接框擦到框角，也不要把圆切掉。
- **活动内的小标签不单独成条**：想一想 / 做一做 / 试一试 / 议一议 / 猜一猜 / 实验与记录 / 交流与小结
  这些是活动内部的行内小标题，文字并入其后的第一条内容条目，**不要用 `heading`**（那会误导 Pass 2 建出子章节）

其余粒度：

- 一个自然段 = 1 条
- 小标题行 = 1 条（章名、节名、节内小标题）
- 一道题（题干 + 选项 + 答案区整体）= 1 条
- 一张图 + 它的图注 = 1 条（`figure`）；一个图注覆盖 (a)(b)(c) 并排子图时算 1 条，bbox 取外接框
- **`figure` 的 `region` 只框图形本身，不含印刷的图注文字行**。
  **但必须包含 `(a)` `(b)` `(c)` 这类子图标号那一行** —— 正文里写「如图 2-23（a）所示」，
  标号被裁掉读者就分不清哪张是哪张。只排除「图 X-Y 说明文字」那一整行。图注文字记在 `text` 字段，
  Pass 2 写进 `assets[].caption`，由阅读器渲染成 `<figcaption>`。
  理由：region 同时是**裁图区域**和**条目覆盖范围**，如果把印刷图注框进去，
  裁出来的图自带一行图注，阅读器再渲染一遍 → 每张图下面出现两次同样的字
- **图注压在图上、裁不掉的例外**：有些图注直接印在照片上（裁掉会切掉画面）。
  这类条目在清单里标 `"captionOnImage": true`，Pass 2 就**不写 `assets[].caption`**、
  把图注文字只放 `alt`。这样裁图完整、图注在图上原样显示、不会出现两遍。
- **一个图注管多大范围，就是一条 `figure`**。图注覆盖不到的部分，只要是同一图号内的组成元素
  （子图、局部放大圆、装饰性对照图），**并进这一条**，region 取它们的外接框。
  只有当**另有一条独立图注**时，才另立 `figure`。
- **复合插图该拆还是该并，看外接框会不会盖到第三方内容**：
  - 会盖到（例如照片 + 放大圆，旁边紧贴警示框）→ **拆**成两条，各自一个矩形，
    第二条 `originalNumber` 写「图 X-Y 局部」，两条互写 `overlaps`
  - 不会盖到（例如照片 + 右上角装饰圆图，周围是空白）→ **并成一条**，不要拆
  例子：八上图 1-11（照片 + 光屏放大圆 + 旁边紧贴激光警示框）该拆；
  八下图 7-28（高速列车照片 + 右上角海豚圆图，周围空白、只有一条图注）该并。
- **同一张图的多个 part 之间可以相交**：局部放大圆本来就画在主照片上，相交是原书事实。
  两条互写 `overlaps` 即可，**不要为了消灭相交去切掉照片或圆弧**。
  但每个 part 都**不得与第三方内容块相交**（别的图、别的栏目框、警示框）
- 一张表格 = 1 条（`table`）
- 章首页：章标题行 1 条（**含章号、章名、章题名**）；章内栏目导航列表按目录处理**不登记**；整页背景照片不登记
- 栏目图标、页眉页脚、页码、装饰底纹、彩色卡片背景、页边竖色带**不算条目**
- 目录、版权页、致同学、封面、封底 = **不登记**
- **双栏排版按栏顺序**：先左栏自上而下，再右栏自上而下
- **浮动的外框不按栏序**：信息快递 / 方法技巧 / 试一试 这类**独立浮框**插在正文中时，
  按它**在页面上的纵向位置**插进阅读顺序，不要为了凑「左栏到底」把它挪到最后。
  纯双栏正文才严格按栏序
- **跨页内容**：在起始页登记 1 条，`continuesOn` 填下一页 pdfPage，并在 `extraRegions` 里给出后续页的 region；下一页不重复登记
- **跨页配图**：图登记在它**实际所在的页**，即使它配的是上一页的活动。归属哪个节点由 Pass 2 按图注与上下文决定

`kind` 取值只有这些：

| kind | 用于 |
|---|---|
| `heading` | 章名、节名（一、二、三）、节内小标题 |
| `para` | 正文自然段 |
| `figure` | 图 + 图注 |
| `table` | 表格 |
| `activity-title` | 「活动 X.Y」「学生实验」的标题行 |
| `block-title` | 栏目标题行：实践与练习 / 素养进阶 / 内容梳理 / 反思提升 / 问题解决 |
| `module` | 成框的栏目块（含警示框、提示框） |
| `exercise` | 「实践与练习」的一道题 |
| `summary` | 「内容梳理」的思维导图 |
| `question` | 「反思提升」「问题解决」的一道题 |

### 3.2 清单格式

Pass 1 只产出清单，**不产节点、不写内容、不建关系**。

```jsonc
{
  "volume": "b8a",
  "chapter": "phy-b8a-c01",
  "pdfPageRange": [19, 25],
  "printedPageRange": ["12", "18"],
  "pageOffset": { "formula": "pdfPage = printedPage + 7" },
  "items": [
    {
      "srcId": "phy-b8a-p012-01",
      "kind": "heading",
      "pdfPage": 19,
      "region": { "x": 0.30, "y": 0.09, "width": 0.40, "height": 0.05 },
      "originalNumber": null,
      "text": "一、声音是什么",
      "parentSrcId": null,
      "overlaps": [],
      "continuesOn": null,
      "extraRegions": []
    }
  ]
}
```

- 每条必须带 `bbox`（`region`）或显式 `regionOmittedReason`。
- 清单冻结后存入 `local-textbook/sukey/expected/`，Pass 2 只读。
- 校验器会把 `region` 叠回页图生成核对图（`local-textbook/sukey/review/`），供人工抽查漏读。

### 3.3 Pass 2 的边界

Pass 2 只做映射：`srcId → 一个或多个节点`。
一个 `srcId` 拆成多个节点时，节点 id 用 `@1`/`@2`，并在节点 `tags` 里保留 `src:<srcId>`。
一个 `note` 吞并了多个连续源条目时，只登记第一个 `srcId` 为节点 id，其余写进 `tags`（`src:phy-b8a-p045-03`）。

### 4.0.1 kind 判不准时，看它将来的父节点

`kind` 不只是标签：Pass 2 会按它决定建什么 `type`，而 `type` 必须满足父容器的 `allowedChildTypes`。
所以判断依据**不是字号大小，而是它会挂在谁下面**：

| 它将来挂在 | 可以是什么 | 推论 |
|---|---|---|
| `branch` | `section` / `note` | 册下面不能直接挂命题、题目、定义 |
| `section` | 任何内容节点 | 章、节下面随便挂 |
| `note` | **只有 `note`** | **栏目内部的小标题不能是 `heading`**，否则建出 `section` 会被判非法 |

由此得出两条硬规则：

1. **栏目内部的小标题一律不是 `heading`**（读一读里的小标题、活动里的 想一想/做一做、跨学科实践里的 任务一/任务二）。
   它们是 `para` 或被并入相邻段落。
2. **`heading` 只留给章名、节名、节内小标题** —— 也就是将来会建成 `section` 的那些。

同理，一个块该不该拆成独立条目，判据也不是「它有没有边框」，而是**拆出来之后它会不会成为别人的子节点、
而那个位置不合法**。嵌在插图里的警示框就是这种：它若拆成 `module`，就会变成 figure 的子节点，非法。

### 4.1 通用映射

表里没有 → `note(explanation)` 兜底 + 写例外清单。

| 教材内容 | type | kind |
|---|---|---|
| 正文讲解段落 / 框内说明 | `note` | `explanation` |
| 确属科学史内容 | `note` | `history` |
| 例题 | `problem` | `example` |
| 学生自己探究并得出条件 | `problem` | `exploration` |
| 物理量、单位、术语定义 | `definition` | 无 |
| 定律 / 原理 / 规律 | `proposition` | `law` / `principle` |
| 独立可引用的公式 | `proposition` | `formula` |
| 实验得出的可引用断言 | `proposition` | `claim` |
| 物理模型 | `note` | `model` |
| 现象描述 | `note` | `phenomenon` |
| 技术过程 | `note` | `process` |
| 器件结构 | `note` | `structure` |
| 编者说明、承上启下 | `note` | `context` |

红线：

- 一般叙述段落**不许**建 `proposition`。命题必须是可判真假的断言。
- **一段里有多种语义时必须拆**：一段同时含「断言 + 定义」时，拆成 `proposition` + `definition`，
  不要把整段塞进一个 `note(explanation)`。
  例：「大量实验表明，声音是由物体振动产生的。物理学中，把正在发声的物体叫作声源（acoustic source）。
  固体、液体、气体都能发声，都可以成为声源。」
  → `proposition(kind='claim')`「声音是由物体振动产生的」+ `definition`「声源」。
- **断言性结论必须建 `proposition`**，否则整本书会退化成一棵只有章节和段落的树：
  无法挂 `supports`（实验支持结论）、无法挂 `covers`（题目考查知识点）、无法建 `InferenceStep`。
  下列一律建命题：定律（`law`）、原理（`principle`）、公式（`formula`）、
  原书用「大量实验表明 / 说明 / 可知 / 结论是」引出的断言（`claim`）、
  「X 与 Y 有关/无关」这类可判真假的定性结论（`claim`）。
- **实验/现象 → 结论的边必须连**：原书某 `note(experiment|phenomenon)` 的数据或观察支持某命题时，
  连 `supports`；某题直接考查某命题/定义时，连 `covers`。这类边有原文依据，属于必须建立的范围，
  不要因为「怕连错」而全部省略。
- 实验结论若立 `proposition`，**挂到所属 `section`**，与 `note(experiment)` 同级。
- 不建 `proof`（初中物理无形式证明，推导写进 `note(explanation)`）、不建 `attempt`、不建 `counterexample`。
- 纯代数变形不立 `formula`。只有作为独立可引用陈述时才立。

## 5. content 写法

- 纯 Markdown，**不要在 content 里重复 `title`**。
  活动/实验节点的 content **不要**再写一遍 `#### 活动 X.Y 标题` —— 标题已在 `title` 里，界面会重复渲染。
- **正文型 `note` 允许 title 与 content 首句重叠**：`title` 取首句开头（≤20 字）作为树里的可读标签，
  `content` 保留整段原文。不要为了消除重叠去删原文，也不要把 title 改成「正文」「段落」这种空标签。
  重复渲染禁令只适用于**结构性标题行**（活动、实验、章、节），不适用于正文段落。
- 层级从 `####` 起（`##` 留给渲染器）
- 行内 `$...$`，独立 `$$...$$`；物理量带单位写 `$5\ \mathrm{m/s}$`，可用 `\pu{}`
- 表格用 GFM，实验数据表保留原表头文字与结构
- 图：`![图片替代文本](asset://phy-b8a-p045-fig01)`
- **图注不进 alt**。图注原文写进 `assets[].caption`（见 §10），由阅读器渲染成 `<figcaption>`
- 原书编号保留在正文，同时填 `citation.originalNumber`
- 不写原书没有的话：不补背景、不解释、不润色、不改写
- 图注缺失 → `caption` 留空，`report.md` 记「p45 图无图注」

## 6. citation

```json
"citation": { "source": "苏科版初中物理八年级上册", "page": "45", "originalNumber": "4.2" }
```

- `page`：**正文的印刷页码**（纯数字字符串）。**章节节点用该章正文起始页，不是目录所在页。**
- `branch` 册节点没有对应印刷页 → **允许不填 `page`**，填 `originalNumber`（如「八年级上册」）。禁止编造页码。
- 无印刷页码的前言、插页、封面 → 不填 `page`，在 `report.md` 记例外。
- `originalNumber`：原书自带编号（活动号/题号/图号），没有就不填。
  **栏目节点例外**：`section(kind='topic')` 与承载栏目的节点，`originalNumber` 写**栏目标题**
  （「实践与练习」「素养进阶」「内容梳理」「信息快递」…）。
  原因在渲染链路 `src/lib/graph.ts` 的 `numberDisplayFor()`：有 `originalNumber` 就直接显示它，
  否则退回 UI 自动编号——那样树上会出现「1.2.3」这种原书不存在的编号。
  所以**审计不要把它当「填错编号」报**，这是八年级定下的约定（见 `exceptions-b8a.md` §6.4）。

## 7. 关系（只用这 7 种）

### 7.0 谓词选择决策表（先查表，再连边）

连边前先问一句「**这句话在说什么**」，按下表路由。查不到的一律不连。

| 原书那句话在说什么 | 谓词 | 起点 → 终点 |
|---|---|---|
| 「需要用到…」「在前面学过…」「根据…可知」，或后文原句真的**用到了**前文概念的语义 | `depends-on` | 内容 → 定义/命题/笔记 |
| 「这个仪器/装置/技术/生活实例**用到了**某个原理或量」 | `uses` | 笔记/题/证明 → 定义/命题/笔记 |
| 「这道题**考查**某个知识点」 | `covers` | 题 → 定义/命题/笔记 |
| 「这个实验/现象的数据或观察**支持**某个结论」 | `supports` | 笔记(实验/现象) → 命题 |
| 「A 是 B 的属性、后果、补充说明」（弱关联，说不出严格依赖） | `cites` | 任意 → 任意 |
| 「X 是 Y 的一种」 | `is-a` | 定义 → 定义 |
| 「X 是 Y 的组成部分」 | `part-of` | 定义 → 定义 |

**最常见的错判**：把「用到了」写成 `depends-on`。两者区别是方向感和强度 ——
`依赖`是「离开它这句不成立」，`使用`是「拿它当工具用」。装置的原理、技术应用、生活实例，
一律是 `uses`，不是 `depends-on`。

**每章的数量参考**（用来判断自己是不是又偷懒或又乱连）：

| 谓词 | 合理量级 |
|---|---|
| `depends-on` | 与本章小节数相当，**每小节 1–3 条**；星形中心超过 3 个就要复查 |
| `uses` | 每个应用/装置/实例 1 条；物理教材通常每章 10–20 条 |
| `covers` | 每题 1–3 条（综合题连全部被考查点） |
| `supports` | 每个实验/现象 1–2 条 |
| `cites` | 不拘，用于属性/后果类弱关联 |
| `is-a` / `part-of` | 物理少见，化学/生物多 |



| 谓词 | 方向 | 依据要求 |
|---|---|---|
| `depends-on` | 后学 → 先学 | 只有两种依据：(a) 原书明写「需要用到…」「在前面学过…」「根据…可知」；(b) **后文原句真的用到了前文概念的语义**——拿它的定义/结论去推出新东西、拿它当前提、拿它当比较基准。两种都要把依据原句抄进 `note`。**必须无环** |
| `uses` | 实验/题目 → 定义/命题 | 原书明确用到某个公式或量的定义 |
| `supports` | `note(experiment/phenomenon)` → `proposition` | 原书用该实验/现象的数据或观察支持某结论 |
| `covers` | `problem` → 知识点 | 该题直接考查的概念。**综合题要连所有被考查的知识点**（一般 2–3 个），只连一个等于把关联丢了；但也不要凑数，连的都是题干实际用到的 |
| `cites` | 任意 → 任意 | 弱引用；跨册回顾旧知识用这个 |
| `part-of` | `definition` → `definition` | 部分—整体，严格区分于 `is-a` |
| `is-a` | `definition` → `definition` | 子类属于上位类 |

- **禁用**：`implies`、`iff`、`proves`、`generalizes`、`refutes`
- **「提到」不等于「用到」**：句子里出现了某个词，不构成依赖。判据是——把这句里的那个概念换成别的，
  这句话是否还成立？**还成立就是只是提到，不许连。**
- **主题概念不能作为依赖目标**：如果目标节点就是本节要讲的对象（例如「三、噪声及其控制」里的「噪声」），
  那么本节内任何节点都不许以它为目标连 `depends-on`。整节都在讲它，每句都会提到它，这种边全是噪声。
  真要表达「这一节在讲噪声」，那是**章节结构**，不是依赖。
- **星形中心要复查**：同一个目标被 ≥ 4 个节点依赖，基本可以断定它是主题词而不是真前置。
  `check:part` 会报 `depends-on-hub` 警告，必须逐条复核。
- **同小节内的依赖要谨慎**：前置依赖通常跨小节（前面学过 → 后面用到）。同一小节内互相 `depends-on`
  十有八九是「同段拆出来的兄弟节点」在互连，`check:part` 会报 `depends-on-same-subsection` 警告。
- `supports` 起点只能是 `note(kind=experiment|phenomenon)`
- 每条边必须能指着原书某句话说清依据，把依据原话写进 `note`
- **零条边好过错一条边**

## 8. 推理步骤

只在原书存在明确、可引用的推理，且前提与结论**都是独立 `proposition` 节点**时创建：

```json
{ "id": "phy-b8b-c10-i001", "premiseIds": ["…A", "…B"], "conclusionId": "…C", "rule": "液体压强与密度关系" }
```

## 9. 跨册实体注册表

文件：`local-textbook/sukey/entities.json`（由合并器维护，**不由转写批次随意写**）

```jsonc
{ "entities": [ { "id": "phy-b8b-p032-01", "key": "pressure", "title": "压强", "aliases": ["压强"], "firstSeen": "phy-b8b-c10-s01" } ] }
```

规则：

- 批次开跑前先查注册表。命中 → 用已有节点 ID 做 `cites`/`depends-on` 目标，**不新建**。
- 未命中且确属核心概念（跨章会被引用）→ `key` 按英文小写连字符命名，`key` 全书唯一。
- 同一概念后续册次再出现：主节点归首次出现处，别处建 `note(explanation|context)` + `cites`。
- 只有「确实不是同一知识实体」才新建节点。
- 册与册之间的合并**串行**（b8a → b8b → b9a → b9b），保证注册表始终最新；册内批次可并行。

```jsonc
  "meta": { "volume": "b8a", "chapter": "phy-b8a-c01", "pdfPageRange": [14, 32], "printedPageRange": ["1", "18"], "agent": "…" },
  "nodes": [ … ],
  "edges": [ … ],
  "steps": [ … ],
  "assets": [
    {
      "id": "phy-b8a-p045-fig01",
      "caption": "图 4-2 用电压表测电压",

    }
  ],
  "exceptions": [ { "srcId": "phy-b8a-p045-07", "reason": "…", "originalText": "…" } ]

```

**字段归属（硬性）**

| 字段 | 谁填 |
|---|---|
| `id`、`type`、`kind`、`title`、`content`、`solution`、`parentId`、`key`、`aliases`、`tags`、`citation` | Pass 2 |
| `order`、`createdAt`、`updatedAt` | **合并器**（按清单顺序 ×1024 生成 order，时间戳取合并时刻） |
| `edges[].id`、`steps[].id`、`assertedBy` | **合并器** |
| `assets[].path`、`sha256`、`byteLength`、`mimeType` | 资源流水线（裁图后回填），Pass 2 不填 |

Pass 2 **不许**填 `order`/`createdAt`/`updatedAt`/`assertedBy`，填了校验器直接报错。
